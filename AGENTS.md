## Project Conventions

- **Component Naming:** Use PascalCase for React components (e.g., `Header.tsx`).
- **File Naming:** Use kebab-case or CamelCase depending on folder conventions (pages and components use PascalCase).
- **Design Approach:** Tailwind CSS with a mobile-first responsive design. The primary theme relies on dark browns (`#2D1810`), amber gradients, and `#E6D8B8` text colors.
